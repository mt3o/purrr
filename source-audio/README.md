# Materiał źródłowy

`fragmenty/` zawiera 24 s mruczenia wyciętego z pełnego nagrania — to jest
materiał, z którego `tools/03_build_bank.py` buduje bank ziaren wbudowany
w `index.html`.

Pełne nagranie (2,5 min, PCM 32-bit / 88,2 kHz, ~110 MB) nie jest w repo ze
względu na rozmiar. Jeśli chcesz powtórzyć wybór fragmentów od zera, wrzuć je
tutaj jako `nagranie.wav` i uruchom `tools/02_rank_segments.py`.

Nazwy plików kodują pochodzenie: `NN_od-do_f0-XXHz.wav`.
